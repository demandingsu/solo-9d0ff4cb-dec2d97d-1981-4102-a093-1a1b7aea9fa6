市政工程投标公告采集与异议追踪 API

公告采集接口

  • POST /api/collect — 传入 {"catalog_url": "..."} 触发采集，成功后整体替换旧结果，失败保留旧结果
  • GET /api/tenders — 各标段当前投标截止时间汇总（冲突标段 status=conflict）
  • GET /api/tenders/{招标编号} — 单标段有效公告链、失效原因与来源链接
  • GET /api/raw — 最近一次采集的原始公告数据

结果公示异议追踪接口

  • POST /api/objections/track — 传入 {"publication_no": "GS-2026-007", "checkpoint": "2026-11-12 00:00:00", "catalog_url": "..."}，沿分页读取异议事项/答复/答复撤销，输出逐事项 answered / unanswered / pending_verify 状态与证据链接
  • GET /api/objections — 最近一次异议追踪结果（含未完成采集时的部分证据）
  • GET /api/objections/raw — 最近一次异议追踪采集到的原始记录

离线样例与文档

  • GET /docs — Swagger 交互文档
  • 公告分页 HTML 样例（/sample，纯静态无外部依赖）
  • 异议记录分页 HTML 样例（覆盖多事项答复、答复撤销、跨页同号冲突、引用缺失）

典型流程

  1. 打开 异议记录样例目录，复制目录第一页 URL
  2. 调用 POST /api/objections/track，给定公示编号与核查时点
  3. 按 unanswered 事项逐一带证据催办；pending_verify 事项人工核实后再定性
